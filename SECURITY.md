# Security policy

Gellou maintains security fixes for the latest release of Roboport Controller. For a problem with the panel, its installer, or its handling of Docker, use [GitHub private vulnerability reporting](https://github.com/Hydrogell/roboport/security/advisories/new).

Include the version from `VERSION`, your installation method, the affected feature and the impact you observed. Remove API keys, recovery codes, cookies, player addresses and other private data from attachments. For a problem in the underlying Factorio Docker image, contact its [maintainers](https://github.com/factoriotools/factorio-docker).

The maintainer aims to acknowledge reports within seven days. Reporter credit is optional. This volunteer project has no paid bounty program.

For help regaining access to your own installation, use the [account recovery guide](deploy/README.md). [Восстановление доступа на русском](deploy/README.ru.md).
